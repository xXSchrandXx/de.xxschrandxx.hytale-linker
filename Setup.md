# Setting up Hytale-Linker
[German](#German) | [English](#English)

## English
1. Install and configure [Hytale-API](https://github.com/xXSchrandXx/de.xxschrandxx.wsc.hytale-api/blob/main/Setup.md) and all required packages and plugins.
2. Install [Hytale-Linker](https://www.woltlab.com/pluginstore/file/7093-Hytale-linker/) via the store code, via the package search or as a file upload.
3. Configure Hytale Linker in the ACP under `Configuration > Options > Hytale > Hytale-Linker`. (A server must be activated in the selection for Hytale Linker to work.)
4. Remember the URL from `sendCode`, `updateNames`, `getLinked` and `getUnlinked` for the step 8.
5. Download [WSC-Linker](https://www.curseforge.com/hytale/mods/wsc-linker) and put it in your `mods` folder.
6. Restart your server.
7. Open the `config.json` in the `WSC-Hytale_WSC-Hytale-Linker` folder.
8. Set `sendCode`, `updateNames`, `getLinked` and `getUnlinked` from step 4.
9. Restart your server.

## German
1. Installieren und konfigurieren Sie [Hytale-API](https://github.com/xXSchrandXx/de.xxschrandxx.hytale-api/blob/main/Setup.md) und alle erforderlichen Pakete und Plugins.
2. Installieren Sie [Hytale-Linker](https://www.woltlab.com/pluginstore/file/7093-Hytale-linker/) über den Store-Code, über die Paketsuche oder als Datei-Upload.
3. Konfigurieren Sie Hytale Linker im ACP unter `Konfiguration > Optionen > Hytale > Hytale-Linker`. (Damit Hytale Linker funktioniert, muss ein Server in der Auswahl aktiviert sein.)
4. Merken Sie sich die URLs von `sendCode`, `updateNames`, `getLinked` und `getUnlinked` für Schritt 8.
5. Laden Sie [WSC-Linker](https://www.curseforge.com/hytale/mods/wsc-linker) herunter und legen Sie es in Ihrem `mods`-Ordner ab.
6. Starten Sie Ihren Server neu.
7. Öffnen Sie die Datei `config.json` im Ordner `WSC-Hytale_WSC-Hytale-Linker`.
8. Legen Sie `sendCode`, `updateNames`, `getLinked` und `getUnlinked` aus Schritt 4 fest.
9. Starten Sie Ihren Server neu.
